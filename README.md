# SeaBubbles Hawaii — Responsive Layout with CSS Flexbox

Fork https://github.com/MarkleyClassroom-CIS130/Starter-SeaBubbles-Hawaii-Dive-in-with-Flexbox into a personal GitHub account. Clone the fork from the command line, open the folder in VS Code, and follow the expandable Canvas lesson. The lesson gives the Git commands, including a commit at the end of each part and a final push.

Open index.html in a browser or a local preview. The initial stacked layout and oversized image are intentional. The starter supplies semantic HTML, content, local assets, and basic visual styles. It intentionally omits the layout, responsive image sizing, media queries, CDN link, and remaining icons. These are added step by step during the lab: type the supplied code, read each explanation, and check the result before continuing.

Targets: four cards at 992px (large), two at 768px (medium), and one at 576px (small); also test 375px (extra small) and 1200px (extra large). Navigation and footer stay usable at every width, card actions align, the hero stays proportional and full width, and the Step 3 icons appear with visible text labels. Source order stays meaningful. Grid, floats, positioning, and frameworks are not used in place of the assigned Flexbox work.

Commit and push after each milestone. Submit the fork URL in Canvas. Include screenshots at 992, 768, and 576 CSS pixels and a REFLECTION.md describing two property experiments, the breakpoint choices, and one bug that was resolved. If Canvas has no URL submission box, follow the instructor's submission directions.

The honu JPG is supplied by the instructor. The sample PDF, "Read Between the Tides," is fictional classroom content, not a usable legal waiver. Font Awesome requires an Internet connection.

The HTML is indented for reading. One decorative water icon is included in the brand as the Step 2 example; it appears after the CDN stylesheet is added in Step 1. The remaining icons are added in Step 3, and the PDF link in Step 14.
