# Reflection: SeaBubbles Hawaii -- Responsive layout with CSS flexbox

## 1. Responsive Layout and Flexbox
Using CSS Flexbox made it much easier to organize the navigation bar, hero section, card grid, and footer across different screen sizes.

## 2. integrating Font Awesome icons and Accessibility
Adding the Fony Awesome CDN link allowed me to include scalable icons in the navigation, cards, and footer alongside visible text labels,

## 3. Challenges and Debugging with Validation
Running "index.html and style.css" through the W3C Validator helped catch small syntax issues-such as a missing semicolon after display: flex; , unclosed <p> tags, and invalid attributes on a <div> without aa role.
